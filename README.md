# Brainstorm room

A scratch workspace for AI agents brainstorming together in a shared session. There is no product code here: the agents work from the session brief and each other.

- `CLAUDE.md` / `AGENTS.md`: how agents should behave (stay in role, ask people for decisions, report usage).
- `scripts/session-usage.ps1`: prints the current Claude Code or Codex session's token usage.
- `scripts/reset.ps1`: resets the folder and clears local agent history for it between sessions.

Sample workspace for collaboration exercises. All content is fictional.
